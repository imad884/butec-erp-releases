# Binary Distribution Policy

This repository contains only public release-distribution metadata and installer artifacts for BUTEC Procurement & Logistics ERP.

Allowed release assets are versioned Windows installers, updater metadata, blockmaps, SHA-256 manifests, and release notes. Application source code, workbook data, credentials, tokens, certificates, private keys, test fixtures, runtime logs, and temporary files are prohibited from both committed content and release assets.

Release publication is performed only by the staged pilot workflow after its repository, credential, artifact-integrity, and operator-confirmation gates pass. The application identity remains `com.butec.erp` and `BUTEC Procurement & Logistics ERP`.
